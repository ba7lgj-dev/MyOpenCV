# Qt 双摄像头检测客户端

基于 Qt Widgets + OpenCV 的双摄像头桌面程序，适配本地 USB/工业相机，支持实时显示、独立检测线与亮度调节、报警推送、CP2102 控制加气以及参数持久化。

## 功能概览
- **双路视频窗口**：主界面两块可伸缩预览框，分别绑定指定的摄像头索引。
- **检测线/阈值/亮度独立调节**：每路相机单独配置检测线高度、二值化阈值、亮度偏移，实时生效。
- **比例标定**：输入实测毫米与像素长度，自动计算 mm/px，显示真实宽度并保存在 `config.json`。
- **告警 & 微信机器人**：为两路相机单独设置阈值与启用开关，低于阈值自动通过 HTTPS 调用企业微信机器人（文本消息）。
- **自动加气**：告警时可选触发 CP2102 端口低电平脉冲（默认 600ms），控制泵机加气，结束后恢复高电平。
- **参数持久化**：界面所有调节项和 webhook 会写入 `config.json`，二次启动自动加载。
- **多线程采集**：每路相机独立线程捕获+处理，界面流畅不阻塞。

## 依赖
- Qt 6（Widgets、Gui、Network、SerialPort 模块）
- OpenCV 4+
- CMake ≥ 3.16

## 构建与运行
```bash
cd cpp
cmake -S . -B build -DCMAKE_PREFIX_PATH=/path/to/Qt
cmake --build build
./build/dual_camera_inspector
```

> 如果环境缺少 OpenCV/Qt，请先安装对应开发包，并将 Qt 安装目录填入 `CMAKE_PREFIX_PATH`。

## 使用步骤
1. 连接两路 USB/工业摄像头，记录索引（默认 0/1，可在 `config.json` 中修改）。
2. 运行程序，主界面出现两个视频窗。
3. 对每路相机：
   - 调整 **检测线高度**、**阈值**、**亮度**。
   - 输入标定的真实宽度和像素长度，点击“根据标定计算比例”得到 mm/px。
   - 勾选“启用告警”并设置毫米阈值；如需自动加气，勾选“低电平触发加气”，填写 CP2102 端口与脉冲时长。
4. 在底部填写企业微信机器人 Webhook，点击“保存参数”。
5. 低于阈值时会自动推送告警，并可选触发加气，宽度实时显示在各自面板上。

## 配置文件
- 位置：`cpp/config.json`
- 内容：每路摄像头索引、检测参数（lineRatio/threshold/brightness/mmPerPixel）、告警阈值、是否告警、是否自动加气、CP2102 端口、脉冲时长、全局 webhook。

## 线程与扩展
- 采集与计算在独立工作线程中执行，Qt 主线程仅负责 UI 更新。
- 可在 `CameraProcessor` 内扩展更多预处理（如滤波、ROI 自定义）。
- 加气控制基于 QtSerialPort，可按需求调整 DTR/RTS 逻辑或串口波特率。
