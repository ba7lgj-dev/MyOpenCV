# 双形态物料宽度准确性与双摄像头协同

有的物料在输送过程中会呈现「扁平形态」与「圆柱形态」两种截面，单路摄像头在不同形态下的像素宽度差异较大，导致真实宽度推算偏差。建议：

1. **双摄像头数据融合**
   - 在 `CameraProcessor` 输出的 `whiteLengthPx` 基础上，为每路配置独立的 `mm/px` 标定值。
   - 在业务层（如 `MainWindow::onAlarm` 前）增加融合策略：
     - 当两路相机同时找到白段时，使用加权平均：`width_mm = w1 * cam1 + w2 * cam2`，默认 w1 = w2 = 0.5；
     - 若其中一路未找到有效段，则退化为另一路的值；
     - 在形态切换频繁的产线，可以根据历史方差自适应调整权重，方差小的相机权重大。

2. **形态自适应阈值**
   - 针对扁平/圆柱形的亮度差，允许在 `config.json` 为每路相机预置两套阈值与亮度偏移，生产时在 UI 中提供“形态切换”按钮即时切换。

3. **物理标定与 ROI 控制**
   - 使用同一根标准棒材分别在两种形态下做标定，得到两组 `mm/px`，再按检测到的形态插值。
   - 缩小 ROI 到物料所在通道，减少背景干扰，避免扁平化时的漏检。

4. **异常检测与回退**
   - 若当前帧宽度与最近 N 帧均值偏差超过设定比例（例如 15%），判定为形态切换或异常，保持上一稳定值并标记为“待确认”。

上述策略可在 UI 层新增切换按钮或在后台定时根据方差自动切换，保证扁平/圆柱形态下都能保持宽度的鲁棒性。
